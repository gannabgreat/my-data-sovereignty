🧪 할 일 1 · 알고리즘 실험 (하루 약 25분)

준비물

  • 실험 전용 새 구글 계정 1개 — 평소 쓰는 계정과 섞이지 않는 새 계정이면 돼요. 전화번호 인증을 요구할 수 있어요
  • 크롬 새 프로필(오른쪽 위 프로필 › 추가) — 평소 계정·쿠키와 섞이지 않게. 폰보다 PC가 캡처·셈이 쉬워요
  • 캡처 도구 (맥: ⌘+⇧+4 / 윈도우: Win+⇧+S)
  • 기록표 (아래 형식, 구글 시트 추천)

0일차 (10/21) — 기준 재기

  1. 새 프로필로 새 계정 로그인 → 내 활동 › YouTube 기록이 켜짐인지 확인
  2. youtube.com 홈을 열고, 아무것도 누르지 않은 채 상위 20개를 캡처
  3. 그중 내 주제 영상이 몇 개인지 세서 기록 (단계 = 기준)

1~5일차 — 주입 (매일 같은 시간대)

  1. 먼저 측정: 홈 새로고침 → 상위 20개 캡처 → 내 주제 영상 수 기록 (단계 = 주입)
  2. 그다음 주입: 주제를 검색해서 영상 10개 (각 2분 이상) + 쇼츠 30개. 주입량을 다르게 정했으면 그 시간만큼
  3. 구독 · 좋아요 · 댓글 · 공유 금지 — 시청만으로 얼마나 물드는지 보는 실험이에요

6~8일차 — 회복

  1. 먼저 측정 (주입 때와 똑같이, 단계 = 회복)
  2. 정한 회복 방법만 하기: 반대 주제만 보기 / 내 주제 영상에 「관심 없음」 / 시청 기록 삭제

세는 규칙 (모두 똑같이)

  • 「상위 20개」 = 홈 맨 위부터 일반 영상 카드 20개. 광고·쇼츠 줄·「뉴스 속보」 같은 묶음 칸은 빼고 세요
  • 내 주제인지는 제목·썸네일·채널 이름으로 판단. 애매하면 X
  • 대조군은 「가장 많이 보이는 주제 하나」를 0일차에 정해 두고 그걸로 세요
  • 결과는 「경향」이지 통계적 증명이 아니에요 — 발표에서도 그렇게 말해요

  1. 진단기 ③ 미션에서 내가 실제로 쓰는 앱 미션 2~3개를 직접 해 보기 (본인 계정)
  2. 몇 번 눌러서 끝났는지 세기 — 화면 하나 넘어갈 때마다 1번
